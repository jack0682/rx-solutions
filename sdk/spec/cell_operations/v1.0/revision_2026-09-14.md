Revision date: 2026-09-14. Reflects the user's decision to make the personal project vendor-neutral. This is **a documentation/device-inclusion policy revision**, not a wire semantic-version change or completion of new execution validation.

## Changes and preservation

Replaced first-installation inputs for a particular customer/product with per-installation operating scope. Actual unresolved inputs remain NOT_COMMISSIONED. Replaced device-specific support obligations and default driver/SDK inclusion with vendor-neutral profile policy. Links in normative documents copied outside this repository were changed to GitHub paths readable from standalone checkouts.

Preserved the meanings of messages, enums, state transitions, fields, canonical intent, identical-request handling, UNKNOWN, fences, permits, observations, and outcome/resource handover. Retained semantic_version `1.0.0` and wire package `rx.cell.v1`. Do not retroactively reinterpret existing records using new profiles.

Adding configuration types does not establish validated support for mobile, facility, or actively balanced devices. Each profile must validate actual model, mode, firmware, observations, authority, startup/shutdown, material support, and timing.

## Counterexample review

- Required package installation does not permit admission without authority, calibration, and observations.
- If driver shutdown disables torque, do not gracefully stop while material support is required. Neutralizing action names does not remove this obligation.
- If different profiles share a controller or material, check conflict/handover conditions through common resources.
- Current idle, zero velocity, mode acceptance, or healthy communication alone does not establish past completion.
- Do not automatically permit mixing new and old schema hashes merely because semantic_version strings match.

This is a documentary semantic comparison, not new native/physical test evidence. Original review/test documents are referenced in the [preservation guide](https://github.com/jack0682/rx_docs/blob/main/references/README.md).
